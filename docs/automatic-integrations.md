# Automatic project setup

Studio scans bounded local manifests, extracting dependency names rather than uploading source code. It ranks the bundled reviewed skill catalog by project stack/task and selects at most three sources. The network request downloads the original resources at their recorded commit from `raw.githubusercontent.com`. Every resource must match the local reviewed manifest SHA-256 before anything is installed. License files and provenance remain alongside the skill. Adapted bundles are excluded because their hashes do not describe original upstream files.

Installed bundles live at `.vibe/skills/auto/<publisher>/<skill>`. SkillLibrary verifies their provenance before loading; role profiles reference `workspace:auto/...`. Repeated setup uses a hash-verified cache. Explicit agent settings and unrelated configuration remain. Skill permissions do not grant extra tools, and required external runtimes remain prerequisites.

For web projects, setup fetches the current `@playwright/mcp` npm metadata and installs the exact version into its own private package under `.vibe/integrations/auto-playwright`, with lifecycle scripts disabled. npm verifies package integrity through its lockfile; version/integrity/source metadata are recorded. The executable entry is resolved inside the installed package and launched with the app's Node runtime in headless mode. It requires npm on PATH and a supported browser installed separately. No project's dependencies are modified.

For projects with dependencies, setup configures the [Context7 remote MCP endpoint](https://github.com/upstash/context7). Existing server configuration, including disabled state and headers, is preserved. Authentication or rate-limit failures are reported, never fabricated as connected. [Playwright MCP](https://github.com/microsoft/playwright-mcp) and Context7 currently form the automatic MCP catalog; other servers remain manually configurable.

The **Tích hợp dự án** panel exposes detected stack, source links/commits/licenses, setup results, and actual MCP diagnostics. Automatic setup is enabled by default, may be switched off, and runs once per detected project signature in each backend session. Explicit setup retries errors. A failing source does not block other sources or normal agent work. `VIBE_AUTO_INTEGRATIONS=0` disables the automatic pre-run hook for offline/headless test environments. This is a reviewed-source catalog, not a claim of third-party certification or arbitrary internet-wide installation.

Verification includes deterministic source fixtures, checksum mismatch rejection, role assignment/cache reuse, symlink exclusion, cancellation/config preservation, WebSocket settings, desktop UI, and a real online React/Vite setup. The live run downloaded three complete skill bundles and connected both Playwright and Context7; browser tools were discovered, not claimed to have executed a browser test.
